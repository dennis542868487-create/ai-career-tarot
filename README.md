# AI Career & Money Tarot Reading

A mobile-first MVP for AI-guided tarot readings focused on career clarity, money blocks, next opportunities, and gentle next steps.

## Current MVP status
This repository currently includes:
- landing page
- reading setup page
- card draw page
- result page
- initial tarot data model
- safe framing and disclaimer copy

This is an MVP skeleton, not the full product yet.

## Local development

```bash
npm install
npm run dev
```

Then open:
- `http://localhost:3000`

## Build check

```bash
npm run build
```
